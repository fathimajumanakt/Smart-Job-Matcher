# 🎯 Smart Job Matcher

## 📌 Project Overview
Smart Job Matcher is a Python-based web application designed to help job seekers discover relevant job opportunities based on their skills, preferred job roles, experience, and location.

The application retrieves job listings through an external JobsForce API and provides estimated skill-matching scores to help users identify relevant opportunities.

## 🚀 Key Features

- Search jobs based on job roles and titles.
- Filter jobs by location and experience.
- Find local and remote job opportunities.
- Match user skills with job requirements.
- Display company names and job descriptions.
- View salary and experience details when available.
- Direct application links for job opportunities.
- User-friendly interactive interface.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Requests
- REST API

## 💻 Installation and Setup

 1. Clone the repository

```bash
git clone https://github.com/fathimajumanakt/Smart-Job-Matcher.git
```

2. Navigate to the project folder:

```bash
cd Smart-Job-Matcher
```

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```
